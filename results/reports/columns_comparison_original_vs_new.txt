[2] 신규 생성본에서 새로 추가된 핵심 실측 CAN 피처 (총 12개)
----------------------------------------------------------------------------------------------------
(과거에는 조향각과 페달, 원시 차체거동 통계가 누락되어 있었으나, 신규 생성본에 전수 복원됨)
  1. lat_accel_mean       : 횡가속도 평균 (0x220)
  2. lat_accel_std        : 횡가속도 표준편차 (0x220)
  3. yaw_rate_mean        : 요레이트 평균 (0x220)
  4. yaw_rate_std         : 요레이트 표준편차 (0x220)
  5. sas_angle_mean       : 조향각 평균 (0x2B0)
  6. sas_angle_std        : 조향각 표준편차 (0x2B0)
  7. sas_angle_p2p        : 조향각 P2P 진폭 (0x2B0)
  8. sas_speed_mean       : 핸들 조향 속도 (0x2B0)
  9. accel_pedal_mean     : 가속 페달 개도율 평균 (0x316)
 10. accel_pedal_max      : 가속 페달 최대 개도율 (0x316)
 11. brake_pedal_mean     : 제동 페달 작동량 평균 (0x316)
 12. brake_pedal_max      : 제동 페달 최대 작동량 (0x316)

[3] 신규 생성본에서 제거된 비물리적/더미/구버전 피처 (총 18개)
----------------------------------------------------------------------------------------------------
(세션 유출을 유발하던 더미 플래그 및 구버전 FFT 가공 피처를 제거하여 데이터 무결성 확보)
  1. session_id                  : 사용자 요청으로 제거
  2. sensor_1                    : 과거 더미 플래그 (유출 원인)
  3. sensor_2                    : 과거 더미 플래그 (유출 원인)
  4. sensor_3                    : 과거 더미 플래그 (유출 원인)
  5. sensor_4                    : 과거 더미 플래그 (유출 원인)
  6. clearance_factor            : 과거 가공 파형 지수
  7. np4                         : 과거 4차 정규화 파워
  8. norm_rolling_var_mean       : 과거 가공 이동 분산
  9. norm_rolling_var_max        : 과거 가공 이동 분산 최대값
 10. norm_p2p                    : 속도 정규화 P2P
 11. norm_rms                    : 속도 정규화 RMS
 12. norm_std                    : 속도 정규화 std
 13. norm_fft_peak_freq          : 과거 FFT 피크 주파수
 14. log_norm_fft_spectral_energy: 과거 FFT 스펙트럼 에너지
 15. fft_spectral_entropy        : 과거 FFT 스펙트럼 엔트로피
 16. norm_fft_spectral_centroid  : 과거 FFT 센트로이드
 17. fft_energy_low_band         : 과거 FFT 저주파 에너지
 18. fft_energy_mid_band         : 과거 FFT 중주파 에너지
 19. fft_energy_high_band        : 과거 FFT 고주파 에너지
